# 🎄 El impostor de la Navidad

Juego de impostor con temática navideña para jugar en grupo con **un solo dispositivo**: se pasa el celular y cada quien ve su palabra en privado.

## Cómo se juega

1. Escribe los nombres de los jugadores (de 3 a 12) y elige categorías, o activa **Mezcla de todas**.
2. Elige cuántos impostores habrá (1 o 2).
3. Pasen el celular: todos ven la misma palabra navideña, menos el impostor, que solo ve la categoría.
4. Cada quien da una pista sin decir la palabra. Después discuten y votan.
5. Si descubren al impostor, gana el grupo. Si el impostor adivina la palabra, gana él.

## Categorías

Comida y bebida, Tradiciones, Personajes, Películas y villancicos, Adornos y regalos, Lugares y clima.

## Tecnología

Un solo archivo `index.html` con HTML, CSS y JavaScript. Sin servidor ni base de datos: el banco de palabras está dentro del código (objeto `BANCO`).

## Agregar palabras

Abre `index.html`, busca `const BANCO` y agrega palabras a la lista de cualquier categoría.
